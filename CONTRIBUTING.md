# Contributing

1. Create a focused branch.
2. Keep changes scoped and avoid collecting additional user data.
3. Run `dotnet test CodexUsageWidget.sln -c Release`.
4. Describe behavioral and privacy implications in the pull request.
5. Never commit Codex session files, authentication files, settings, logs, or
   other user data.

Bug reports should include copied diagnostics and reproduction steps, not raw
session contents.
